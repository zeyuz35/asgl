## 2024-06-02 - Optimize CVXPY canonicalization using vector inner products
**Learning:** In CVXPY, `cp.sum(cp.multiply(weights, beta_var))` and `cp.norm1(cp.multiply(weights, beta_var))` generate enormous AST expressions that scale poorly during the canonicalization phase, especially in high dimensions or across many groups. However, equivalent expressions using vector inner products (like `np.abs(weights) @ cp.abs(beta_var)`) compile down to single, compact constraints, dropping canonicalization time by >90% without negatively impacting actual solver performance. Note: `cp.sum_squares(cp.multiply(..., ...))` is an exception and should be left alone, as changing it to inner products with `cp.square(...)` drastically inflates actual solver execution time. Additionally, for logistic regression, `cp.sum(cp.logistic(pred) - cp.multiply(y, pred))` on flattened arrays should be changed to `cp.sum(cp.logistic(pred)) - y.T @ pred`.
**Action:** Replace `cp.sum(cp.multiply(...))` and `cp.norm1(cp.multiply(...))` with vector inner products (`@`) using `np.abs(...)` on constants to respect DCP rules, and leave `cp.sum_squares(cp.multiply(...))` as is.
