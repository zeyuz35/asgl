## 2024-05-29 - Docstring Default Formatting Consistency
**Learning:** Default parameter values in docstrings should be formatted consistently without spaces around the equals sign (e.g., `default='value'`, not `default = 'value'`), and typos like `defaul` can occur.
**Action:** Always check parameter descriptions for formatting inconsistencies and typos like "defaul=" or "default = ".
