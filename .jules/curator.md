## 2024-05-24 - Pandas vs PySpark DataFrame Columns Logic Bug
**Learning:** `asgl.base_model` has a bug in its feature name extraction from inputs like pandas DataFrames. It uses `if hasattr(X, "columns") and callable(getattr(X, "columns", None)):` instead of `not callable(...)`. This causes it to completely fail to extract feature names from Pandas DataFrames (where `.columns` is a property/Index object), and it incorrectly tries to extract them from PySpark DataFrames (where `.columns` is a callable method) resulting in setting `feature_names_in_` to a bound method object instead of an array of strings.
**Action:** When extracting feature names from structured array wrappers, use `if hasattr(X, 'columns') and not callable(getattr(X, 'columns', None)):` to ensure we capture Pandas Dataframe columns and prevent storing bound methods from PySpark dataframes as feature names.
