## 2024-05-22 - Resolve unused variables and clean up imports
**Learning:** Method-level imports can mask dependencies and should be moved to the top-level module where possible. In Python, especially with scikit-learn, backward compatibility might require wrapping imports in try-except blocks. When removing seemingly unused variables in test files, they might be identically named elsewhere in tests, making targeted \# noqa exclusions safer than global replacements or outright deletion if they document expected arguments or structures implicitly.
**Action:** When working on sklearn-compatible estimators, check method-level imports like `_tags` and move them up. Use `# noqa: F841` for unused variables in test suites where removing them completely is risky due to test fragility or test repetition. Ensure unused imports are safely removed across the board.
