## 2024-05-15 - Optimize CVXPY element-wise multiplications into inner products
**Learning:** CVXPY canonicalization time is extremely sensitive to expression graph size. Using `cp.multiply()` followed by `cp.sum()` or implicitly wrapping it in `cp.norm1()` generates massive expression trees that drastically increase problem compilation time. However, using matrix or vector inner products (e.g., `@`) represents the exact same operation mathematically but heavily shrinks the graph size, improving setup performance.
**Action:** Always prefer `@` over `cp.multiply` when the variables are aligned for dot products, except for `cp.sum_squares` which has highly optimized canonicalization rules and should not be split into dot products with `cp.square`. Also, be careful when applying dot products with sparse matrices.
