## 2024-05-21 - Optimize CVXPY Expressions using Vector Inner Products
**Learning:** Element-wise operations like `cp.multiply` inside `cp.sum` or `cp.norm1` drastically increase CVXPY canonicalization time by building complex expression trees, especially for matrix variables (like multi-output regression). Replacing `cp.sum(cp.multiply(A, B))` with `A.T @ B` avoids element-wise constraints. However, be careful not to replace `cp.sum_squares(cp.multiply(A, B))` with `(A**2).T @ cp.square(B)`, because `cp.sum_squares` canonicalizes efficiently into a single constraint, while `cp.square` explodes solver execution time.
**Action:** When creating a CVXPY penalization expression, replace L1 norm and scalar sum element-wise products with `@` (e.g., `cp.sum(W.T @ cp.abs(beta_var))` or `W.T @ group_norms`) but leave `cp.sum_squares` formulations intact.
