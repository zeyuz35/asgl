## 2024-05-18 - [Optimize CVXPY aggregations using explicit inner products]
**Learning:** Using `cp.multiply` followed by aggregation functions like `cp.sum` or `cp.sum_squares` in CVXPY is significantly slower to canonicalize than using explicit inner products (`@`). For logistic loss, `cp.sum(cp.logistic(pred)) - y.T @ pred` is much faster than `cp.sum(cp.logistic(pred) - cp.multiply(y, pred))`. Similar optimizations apply to structured penalizations where element-wise multiplication with a weight vector can be re-written as an inner product. For matrix variables, `np.square(weights).reshape(-1) @ cp.sum(cp.square(beta_var), axis=1)` correctly computes the sum-of-squares with broadcasting, avoiding slower canonicalization.
**Action:** Replace CVXPY `multiply` followed by a summation across dimensions with a direct inner product whenever mathematically equivalent to optimize solver canonicalization time.
