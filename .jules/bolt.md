## 2024-05-12 - CVXPY Canonicalization Performance
**Learning:** CVXPY canonicalization performance can be significantly improved by replacing element-wise multiplications with vector inner products. Specifically, replacing `cp.sum_squares(cp.multiply(weights, beta_var))` with `cp.sum((weights**2) @ cp.square(beta_var))` and `cp.norm1(cp.multiply(weights, beta_var))` with `cp.sum(weights @ cp.abs(beta_var))` yields 3x faster canonicalization for aridge and slight improvement for alasso, by reducing expression tree size. Wait, memory says: "When optimizing CVXPY expression trees by replacing cp.sum(cp.multiply(weights, norms)) with a vector dot product (weights @ norms), ensure the weights array is strictly non-negative." Since adaptive weights (`individual_weights_`) in `asgl` are non-negative, this is safe to apply.
